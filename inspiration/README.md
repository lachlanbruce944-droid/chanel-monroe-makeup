# Inspiration references

`credits.csv` lists 1,109 Instagram posts used as style references for the site's Inspiration section, 30 per style.
Columns: file name, style, source (followed account or hashtag), artist handle, artist profile, post link, date, size, caption.

The images belong to the credited artists and are kept privately, not in this repository.
Ask each artist's permission before showing their image on the site, and credit them using the handle here.
